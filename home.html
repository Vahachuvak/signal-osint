SIGNAL / 00 ─ OVERVIEW

Find the signal in public data.

Signal OSINT is a workspace for responsible open-source research. Look up public profiles by username, name, or ORCID iD, investigate websites without touching them, and export structured reports. All results come from public sources.

Start people search ↗Investigate a website ↗
01 / PEOPLE◉

Find public profiles.

Search by username, full name, or ORCID iD across more than a dozen public sources, then explore the connections in an interactive graph.

  • GitHub, GitLab, Wikipedia, Bluesky, Mastodon, and more
  • Manual search links for search engines
  • Local history with JSON and Markdown exports
Open the workspace ↗
02 / SITES◇

Investigate websites passively.

Enter an address and Signal checks DNS, HTTP, TLS, security headers, links, technology hints, and public metadata in a few bounded requests.

  • 20 modules, from DNS to sitemap
  • Relationship graph and saved history
  • JSON, Markdown, and SVG exports
Open the workspace ↗
03 / PRINCIPLES◈

Public sources only.

Signal does not search leaked databases, test passwords, or exploit anything. A result is a hint, never a proof of identity or of safety.

  • No leaked data, scanning, or exploitation
  • Verify every finding independently
  • Respect the law and privacy

HOW IT WORKS
01

Choose a workspace
